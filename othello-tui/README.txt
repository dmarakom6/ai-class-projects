Othello vs Minimax
==================

To run the game:

Install the uv python package manager:

```
pip install uv
```

Then:

```
cd othello-tui && uv venv .venv && uv pip install --python .venv/bin/python -e . && .venv/bin/othello-tui
```

If prompted by the terminal about creating a new virtual environment, type `y` and press Enter.
